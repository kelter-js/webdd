# Fade RPG

Пошаговая 2D RPG с элементами хоррора и визуальной новеллы, сделанная на React с использованием Zustand, MUI и Motion для анимаций.

Проект, над которым я работал на протяжении полугода — своего рода личный челлендж: смогу ли я довести до конца полноценную игру?

---

## О проекте

Это был сложный опыт не только с точки зрения программирования, но и как первый шаг в геймдеве.

В процессе разработки встретилось гораздо больше архитектурных нюансов и подводных камней, чем ожидалось:

- организация состояния и логики игры
- управление анимациями
- структура проекта
- баланс между UI и игровыми механиками
- реализоация диалоговых ветвей с учетом различных флагов
- Sequencer для исполнения эффектов и передачи хода между противниками и переключения ходов

---

## Важная информация

Проект распространяется as is.

Если вы столкнулись с критическими (game-breaking) багами, пожалуйста, напишите мне в личку и приложите логи из консоли браузера.
